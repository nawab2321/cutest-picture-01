# Winter Cuddle

A deterministic image entry for make.fun's “Make the cutest picture” bounty: a fluffy orange-and-white kitten cuddling a tiny cream puppy in a cozy winter scene.

## Run

```sh
python3 main.py
```

The program copies the bundled `entry.png` to `/output/entry.png`. For local runs, set `MAKEFUN_OUTPUT_DIR` to choose another output directory. It uses only the Python standard library and makes no network requests.
